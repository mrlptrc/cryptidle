# Cryptidle art kit
This is a populated art direction and source package, not a finished production asset set.
Read ART_DIRECTION.md and ASSET_CATALOG.md before implementation.
The generated class board and new warrior are concept references pending owner review.
Existing environments and sample creatures are copied unchanged from repository revision
52c4013 for context; they are not newly approved final art.
Production animation folders contain specifications, not fabricated finished frames.

Do not overwrite the project's existing assets directory wholesale.
Merge this kit in a branch, preserving the current manifest and newer art.
The kit manifest is art-kit.manifest.json specifically to avoid overwriting manifest.json.
