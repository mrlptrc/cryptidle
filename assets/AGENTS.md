# Art-specific instructions
Follow root instructions as well as this file.
Read ART_DIRECTION.md, ASSET_CATALOG.md and art-kit.manifest.json before editing.
Use approved assets when available. This kit contains no owner-approved production set.
Do not substitute missing character art with rectangles, procedural geometric figures,
SVG or canvas drawings without explicit owner authorization.
Never label concept images, duplicated frames, translated static images, or placeholders
as completed animation. Preserve a working fallback and report missing art.
Do not import reference images into runtime automatically.
Never overwrite production textures based on a filename match alone.
Inspect dimensions, alpha, orientation, frame consistency and real game-scale previews.
Keep source images intact; export derivatives separately.
Use image generation/editing tools for visual changes when available; tooling may assemble
and validate frames, but must not invent unseen animation content.
No reward, damage, cooldown or inventory mutation belongs in animation callbacks.
Record source, status, changes, review evidence and approval separately.
